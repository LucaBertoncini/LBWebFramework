### `TemplateEngine.pas`
A lightweight templating engine: escaped values `{{field}}` (nested paths), raw values `{{{field}}}`, `{{#each}}` (nestable, with `{{else}}`), `{{#if}}`/`{{#unless}}`, parent scope `{{../field}}` and recursive partials `{{> name}}`. See [TemplateEngine.md](TemplateEngine.md) for the reference and worked examples.
